- 2026-11-14 (T13, Daniel): Hospital records are made by `pipeline/data/make_hospital_records.py` (seed `<patient>-T13-20261114`). Visit dates: the three hospitals are put in a random order per patient; the latest visit is 2 to 21 days before 18 Nov 2021 and never before the newest current medicine, the middle one 30 to 120 days earlier, the earliest 90 to 365 days before that. Each hospital writes what was true on its visit date (allergies, diagnoses and current medicines started by then); a stopped medicine is written as stopped by the first hospital visited after the stop, and later ones stay silent. Up to 2 traps per patient: stop only one hospital records (earliest visit moved to 3 to 14 days before the stop and lists it as current), dose change (earliest of at least two hospitals that see a regular single-drug mg medicine writes half the dose, or double if half is an odd size), allergy one hospital misses (a drug allergy if any; "no known allergies" if it was the only one), and a medicine the latest hospital stays silent on (only if it still lists another). Allergy traps are tried first. Every trap is listed in plain words in `pipeline/data/traps/<split>_traps.csv`, because the answer-key format in shared/ has no field to label it. The templates now accept an optional `dose` per medicine for the dose-change trap. P001-P005 written; the other working patients and the held-out ones are T16.

- 2026-11-14 (T20, Daniel): Every model call goes through `pipeline/tool/saved_calls.py`. `call_or_replay()` makes a call only if that record has no saved reply in the run; otherwise it replays the saved one with no call. `load_saved()` can never call, so Check, omission check, compile and scoring use it. Each call is saved in `outputs/extracted/<run_id>/` as `P014_A.raw.txt` (exact reply) and a new `P014_A.call.json` (model, prompt version, settings sent with the prompt and record text replaced by sha256 fingerprints, token usage, stop reason, time, fingerprints of the record, prompt and reply); the retry is `.attempt2`. Saved files are never overwritten. Replay stops if the record or prompt file has changed or the reply was edited; the fix is a new run ID. `saved_calls.py usage <run_id>` prints tokens per call and totals and writes `usage.csv` (for T21); `saved_calls.py pending <run_id> P001 ...` says how many new calls a run would make (for the more-than-10-calls check). The two new file names (`.call.json`, `usage.csv`) are added to shared/folders_and_names.md. Tested with a pretend model on D001 only; no real call made. (T20)
- 2026-11-14 (T22, Daniel): Check step in `pipeline/tool/check.py`. For each fact read from one hospital record it checks the shape (shared/schema/extracted.schema.json), that the status is allowed for the type, that the quote is in the record word for word (only line breaks and spacing may differ), that the name as written is inside the quote, and that the dose's number is in the quote ("1000 mg" may be written "1 g"). A fact that fails a check is kept with the `unverified` flag, not dropped. Brand names become generics from shared/brand_to_generic.csv and shared/drug_list.csv, ignoring capitals, exact matches before partial ones, longest name first; "and", "with", "+" and "&" between drug names count as "/", so "amoxicillin and clavulanate" stays a combination. A name in neither table is set to null with `unknown_name`, never guessed. Also: "1 g" becomes "1000 mg", current medicines with no dose get `missing_dose`. One retry: any failed check except an unknown name earns it; the extract step makes the second call through `check_with_retry()` and saves it as `<P>_<H>.attempt2.json`; of the two tries the one with fewer problems is kept (the retry wins a tie), and there is never a third call. The command line (`--run <run_id>`) reads saved files only, writes outputs/checked/<run_id>/ plus check_report.json, and lists records that still need their retry. Tested with 26 checks: perfect readings of D001 and all 20 working patients pass with no problems, and after Compile all 20 match their answer keys on name, status, dose and flags. No model calls, no held-out file opened. (T22)
