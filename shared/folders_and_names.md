## One patient's folder

Every patient folder (`demo/`, `working/`, `heldout/`, `reserve/`) holds the same five files:

| File | What it is | Made by |
| --- | --- | --- |
| `P014_synthea.json` | The trimmed facts taken from Synthea (the fixed set picked in T04/T11) | Trim script |
| `P014_A.csv` | Hospital A record: CSV table | Template |
| `P014_B.txt` | Hospital B record: free-text note | Template |
| `P014_C.txt` | Hospital C record: brand-name layout | Template |
| `P014_key.json` | Answer key, compiled shape, `kind: answer_key` | Answer-key script |

Hospital letter always means the same format: **A = CSV, B = free-text note, C = brand names.** Scripts that read records pick them up with the pattern `*_[ABC].csv` / `*_[ABC].txt`, so the key and the Synthea file can never be fed to the model by mistake.

## Run IDs

Every run of the tool, and every row of the build-up table, gets its own run ID:

`<YYYYMMDD>-<prompt_version>-<model>`, for example `20261115-v1-sonnet-5-5`, `20261115-v2-haiku-5-5`.

Add a short suffix only if you rerun the same thing on the same day: `20261115-v2-haiku-5-5-b`. The frozen held-out run is the one at the git tag `freeze`; its run ID goes in the Log tab.

## The app and its data

Vercel builds from `app/` only, so the app can't rely on reading `../outputs` at build time. Theo keeps a small sync script in `app/` that copies `outputs/published/` into `app/data/`, and commits the copy. That keeps the deploy self-contained and keeps everyone in their own folder.

## Naming rules

- Folders and code files: lowercase `snake_case` (`compile.py`, `omission_check.py`). App files follow Next.js conventions.
- Patient IDs uppercase: `P001` to `P100`, reserve `R001` to `R080`, demo `D001`. Always three digits.
- Dates in files and names: `YYYY-MM-DD` or `YYYYMMDD`, never `14/11`.
- No spaces in any file name.
- All text files UTF-8. CSVs have a header row and use commas.
- Prompts: `pipeline/tool/prompts/extract_v1.md`, `extract_v2.md`. The prompt version in every output file matches the file name.
